# Lighthouse

A auditoria final está em execução. O script `npm run audit` produz três relatórios HTML/JSON por página/perfil, quatro categorias, LCP, CLS, TBT e medianas em `reports/lighthouse/summary.json`. As medições usam o build completo e o preview com gzip, com MSW e Socket.IO ativos. Os resultados finais serão registrados neste arquivo ao concluir a auditoria.
